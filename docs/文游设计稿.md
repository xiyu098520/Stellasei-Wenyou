# 文游 · 设计稿

> 状态：讨论稿，尚未开工。所有条目都可以推翻。
> 名字「文游」是暂定名，随时可换。

---

## 0. 一句话

给一个世界观（原著＋平行时空＋自己的设定），AI 演这个世界里的所有人，玩家演主角，剧情不断往前推、不会忘事、写出来是一段段有动作有台词的正文。

---

## 1. 玩家的一次完整体验

1. **建一个文游**：只填两格——名字、有没有原著（有就填作品名，联网默认开着）。点「开始」直接进**世界设定页**：一页纸，四块空着，点哪都能写。不想自己写，就拉开右边的小助手（见 §10）。
2. **建角色**：从原著里挑人、改他们的身份与关系，再录入自己的原创角色（OC）。不会写就跟它聊着写（见 §10.4）。
3. **开演**：玩家写一句草稿——「此时，我惊讶地眨了眨眼，说了句『你这人也太奇怪了吧！』」
4. **系统先扩写**：把草稿补成正文（眼睛怎么眨、语气是恼还是笑），再让在场的人各自反应。
5. **多条线并走**：A 来找你说话，你没理 A，转头去找 B。系统要记得 A 被晾着，并在下一次让他有反应。
6. **想反悔**：回溯到任意一条消息之前，世界线整体退回去，之后的世界覆写重来。
7. **听**：打开语音，只念台词，动作和旁白不念，每个人是自己那把嗓子。

## 2. 概念与数据

| 概念 | 说明 |
| --- | --- |
| **文游项目** | 一个平行时空＝一条独立的时间线。自带一批角色、一本设定书、一条存档。 |
| **角色卡** | 名字、身份、说话方式、音色是核心几格；其余格子**不预设**，由玩家自己加（技能值、攻击力、禁忌、持有物……）。属于某本文游，不与其他文游共享。 |
| **世界书** | 两层：**设定书**（这个世界的事实）＋ **风格书**（怎么说话）。见 §2.1。 |
| **存档** | 单线，一条。带完整状态快照列表（§7）。 |
| **事件流水** | 只增的剧情账本：谁在哪、发生了什么、答应了什么。 |

### 2.1 世界书的两层

| | 设定书 | 风格书 |
| --- | --- | --- |
| 管什么 | 人物、地点、组织、时间线、专有名词 | 语气、口癖、禁语、梗、黑话 |
| 归属 | 属于某个文游 | 独立，可挂给多个文游 |
| 注入方式 | **关键词触发**（提到「学院祭」才注入那一节） | **每轮都注入** |
| 例子 | 「星球学院：三个年级，学制四年……」 | 「不要总结、不要替读者感慨、不说『我理解你的感受』」 |

风格书是解决「AI 味」的地方：问题常常不是设定不够，而是没告诉它**不许怎么写**。

设定书里除文字条目外，还允许**自订数值格**（初始技能值、攻击力、势力好感……）——与角色卡是同一套「加一格」机制（§10.4），不需要我们预先定义属性表。

### 2.2 封面与列表卡

每个文游有**一张自己的封面**。列表里不另设信息条——**封面本身就是卡**，文字压在下沿。

| 项 | 说明 |
| --- | --- |
| **封面即卡** | 一张文游＝一张横图，图占满整卡；不切多段色条、不排标签墙。 |
| **尺寸** | 约 16:10 横版；贴边、直角，外一圈细边加一层浅影，像一张相纸。 |
| **默认封面** | 世界一建出来就生成，不必先去找图；也**不再有「没有封面」的卡**。 |
| **换封面** | 部署后玩家自己上传，入口是封面右上角的 `换封面`。**首版只做上传，不接图片生成**。 |
| **下沿名字块** | 极小一行来源（`原著 · 崩坏：星穹铁道`）＋ 世界名（大）＋ 一行状态（章节 · 回合 · 上次时间），右侧是本命角色的小圆头像组。 |
| **可读性** | 下沿压一层「透明 → 米白」的渐变：默认封面浅，换成照片也不糊。 |
| **更多** | 右上角 `⋯`：编辑、删除、复制这个世界。 |

封面右上角常驻一枚 `换封面`——这是玩家最常改的一格，不能藏进设置里。

**没有「封面待定」这个状态**：世界一建出来就带默认封面，所以列表里不会出现虚线空卡。还没开演的世界只是状态行写「还没有开始 · 0 回合」。

列表末尾是 `＋ 开一个新世界`。

## 3. 记忆架构

不靠超长上下文，靠四本分开记的账，每次只取当前这一幕用得上的部分。

| 层 | 内容 | 变化频率 |
| --- | --- | --- |
| **设定库** | 世界观铁律、地点、组织、名词表 | 几乎不变 |
| **角色状态** | 每个角色对你的态度、知道什么、欠你什么 | 慢变 |
| **事件流水** | 按时间排的「发生了什么」 | 只增 |
| **伏笔账** | 埋下但没回收的线（约定、秘密、悬念） | 增、销 |

关键：**角色状态要按人分开存**。A 不知道你私下跟 B 说了什么，除非当时在场。

## 4. 生成架构

一个模型不够，拆成三层各司其职：

| 层 | 做什么 | 何时跑 |
| --- | --- | --- |
| **导演** | 决定下一拍：谁出现、什么冲突、什么时机、推进哪条伏笔 | 玩家每次输入后先跑一次 |
| **演员** | 各自按自己的性格、记忆、信息差决定说什么 | 每个在场角色一份 |
| **叙述** | 把结果写成正文：动作、神态、环境、台词 | 最后一道 |

三层分开的好处：导演负责「有事发生」，叙述负责「写得好看」。如果只有一个模型等你开口，剧情会停在你面前。

> 三层是**职责**分层，不是必须三次调用。默认合成一次请求输出多段，只有角色多、冲突重时才拆开跑（见 §12）。

### 4.1 输出必须分段

不能用一整段散文，必须带类型和说话人，否则语音、回溯、在场表都无从下手。

```
[动作] 她把杯子往桌上一放，杯底磕出一声脆响。
[台词 · 某角色]「你走。」
[旁白] 屋里安静下来。
```

三类：`动作`（主角的）、`台词`（带说话人）、`旁白`。只有 `台词` 送去合成语音。

### 4.2 草稿扩写

玩家写的是**意图**，不是台词。系统先补成正文，再让角色回应。

两条铁律：

1. **不改意思**：把「眨眼」写成「被他说得一怔，睫毛抖了两下」可以；加一句「然后我答应了他」不行。
2. **不替玩家选择**：任何决定权都留在玩家手里。

不满意的扩写可以单条重写，不必回溯整条线。

### 4.3 回复建议

每次 AI 回复之后，附带 **2–3 个**给玩家用的回复选项。作用是「不知道该怎么接」时有个台阶，不是替玩家做决定。

三条要求：

1. **三选一要不一样**，不能是同义改写。默认给三个方向：**顺着接**（软）、**顶回去**（硬）、**岔开**（转移话题／反问）。
2. **不剧透**：选项只能基于玩家**当时知道的事**，不能替玩家「猜中」还没揭晓的真相。
3. **短**：每条控制在一句话，它只是草稿的种子，点下去之后照 §4.2 扩写。

点击行为（已定）：**填进输入框并可编辑**，不自动发送；玩家也可以在输入框里自己加、自己改，或者从头手写。

成本与开关（已定）：选项和主回复**同一次输出**产出（多几十个 token），不单独再调一次；设置里有一枚**总开关**，关掉之后就不再生成。

## 5. 群像机制

玩家演主角，AI 演全世界。要同时管三件事：

- **在场表**：此刻谁在同一空间，谁在门外，谁根本不知道这件事。
- **信息差**：各人掌握的信息分开记；A 的猜疑不能是 B 的已知。
- **接话权**：谁先反应、谁沉默、谁打断。不能每次都是最热情的那个抢答。

被晾着的角色要有后续：A 说过话而你转头找了 B，A 的下一拍必须体现这件事。

## 6. 节奏

**世界停住**：玩家不说话，世界就不动。没有计时器，没有自动推进。

导演只在玩家输入之后跑一次，决定这一拍发生什么，然后交回玩家。

### 6.1 回合与章节

- **一回合**＝玩家说一次话（卡上那行「42 回合」就是它）。
- 默认**按章节走**：每章默认 24 回合（可选 12 / 24 / 48 / 自定义）。这只是「可以翻章」的许可线，不是硬切。
- 到了额度还要落在**自然断点**（放学、回家、睡下、一件事谈完）才翻；玩家也可随时在章节条上点「翻到下一章」。
- 序章固定为「**序章 · 你进入这个世界的由头**」，任务是把你放进世界、把主要人物亮一遍；这件事完成＋断点 → 自动进第一章。章名由 AI 起，可改。
- **世界没有终点**：这条写进设定书、凌驾各章之上——导演只把这一章收在能停的地方，不写大结局；章号可以无限往后。
- 另一档：**只记回合、不自动翻章**（日常流）。回合照加，章停在原处，想翻自己点。

## 7. 回溯

**单线、覆写**。

- 回溯到某条消息＝后面全部截掉，不回退成树，不保留支线。
- **不能只删聊天记录**：角色态度、知道的事、答应过谁，全部一起退回。所以每次推送前落一份**状态快照**（消息＋角色状态＋事件流水＋伏笔账）。
- **重掷**不单独做，它就是「回溯到上一条，再生成一次」——一套机制两用。

---

## 8. 语音

音色按角色配，一个角色一把嗓子。

播放规则：

- 只念 `台词` 段；`动作`、`旁白` 不念。
- 同一段里多人说话时，按段切、各用各自的音色，排队播。
- 音色、语速、情绪可按角色单独调。

引擎沿用现有的一套（MiniMax / ElevenLabs / OpenAI 兼容 / 硅基流动），不新造。

## 9. 联网

不是「会搜索」，是**会沉淀**。而且**它是世界设定页自己的一个动作，不是小助手的专属功能**。

- 开关挂在世界设定页上（有原著才有），默认开。你自己已经填了一堆设定，也可以随时开它。
- 开了之后**它在后台自己跑，不跳页、不弹窗、不打断你**。
- 跑完在页面上挂一条待办：`联网查回 26 条 · 已写进 8 条 · 过一眼 ›`。挂着不挡路，你不管它就不进库。
- **不给你两百条**。判断标准只有一句：**这条跟你的平行时空打不打架**。据此分三类——
  - **直接写**：跟学院不冲突（星神、命途、公司、雅利洛-VI…），直接落进去。
  - **改一下**：跟着你的设定改（列车组 → 学院同好会）。
  - **不写**：跟你这条线冲突的（开拓者主线 vs「不要战争」），自己压着，并告诉你丢了什么。
- **你手填的设定就是它的筛子**：你写得越多，它删得越准。写了「不要战争线」，它自己就把主线划进「不写」。
- 落进去的条目**条尾标 `查到的`，跟手写的一模一样，能改能删**。
- 之后剧情靠本地设定库跑，不必每句重查；想补充，随时再说一句「再查一次」。

## 10. 引导式创建（跟小助手聊出来）

多数人（包括作者本人）不会写设定集。所以创建世界有两条并行的路：**填几格**，或者**直接跟它说**。

### 10.1 新建世界：只有两格

开新世界只问两件事，填完就进去：

| 格 | 说明 |
| --- | --- |
| **剧本名字** | 必填。空着不让开始；提示写在输入框下面，不弹窗、不变红。 |
| **是否有原著作品** | 二选一：`有原著` / `原创`；选 `有原著` 才展开 `作品名` 一格与 `联网查询原著` 开关（默认开启）。 |

底部只有一枚按钮，跟着开关变：开着写 `开始联网查询`，关掉写 `开始手动填写`；联网开着时，手动填写暂不可用。

没有第 2 步，没有「基础事件设定」，也没有必填的目录。点 `开始` 就直接进**世界设定页**（§10.3），四块全空着。

**空不是错误**：空着的块写 `空 · 点开写`，不写「暂无」、不标红、不提示。空着也能一路走到建角色、开演，回头再补。

### 10.2 世界小助手

不是页面，是**从右边拉开的侧窗**。它压在世界设定页上，往左边那一页里加东西。

- 它先读那一页上已经有的东西，开口一句短问：「你想写个什么样的世界？一句话就行。」
- 玩家随口说（「崩坏星穹铁道的平行时空，叫星穹学院，我是大一新生，不要战争线，还有两个原创角色」）。
- **它边聊边记，但不出整页**：每轮只在气泡下记几行小字——`记下：星穹学院`、`排除：不写战争线`、`待办：2 个原创角色`。
- **查原著也是在这一格里说完的**：玩家说「查一下原著的基础设定」，它按 §9 分三类回（`直接写 12 · 改一下 6 · 不写 4`），直接写的落到左边那一页，不写的先压着。
- 它继续问最影响演出的那几件：几个年级、宿舍怎么分、有没有不能提的事。
- 关掉侧窗，就回到你刚才在改的那一行。

### 10.3 世界设定：一页纸，没有「定稿」这个动作

- **新建页和世界设定页是同一页**，不是两页两态。手写的、它补的、查到的，全部落在这，点哪行都能直接改。
- 顶部：世界名 ＋ 一句话简介（点一下就能写）；下面是折叠目录，每行只有块名＋条数，点开才展开正文。
- **没有「下一步」，也没有「定稿」按钮**：底部只有一枚 `就这样，去建角色`，随时可点，空着也能点。
- 右上角 `跟它聊` 拉开侧窗（§10.2），不是跳到另一个页面。
- **目录本身不固定**，分两种块：
  - **固定骨架（4 块）**：世界总览 / 地点 / 人物 / 文风。每本文游都有，可以是空的，但不删。空态写 `空 · 点开写`。世界名与一句话不进目录，永远压在标题下。
  - **`人物` 这一块就是角色卡列表**：点开是一张张卡，末尾一行 `＋ 新建一张`（进 §10.4）。世界里的人不写成文字条目，一律以卡的形式存在。
  - **长出来的块**：种族与命途、学院规则、任务体系、穿着规则、社团、货币……**哪本有哪本没有，全看聊到哪**。行尾标 `它起的`。
  - 目录末尾一行 `＋ 加一块`，玩家自己也能起一个块（跟角色卡同一套「加一格」）。
- **人物**按四段式写：`能力` / `学院背景` / `原著内核` / `学园风性格`——四段各自标来源，查到的内核不许改。
- **每条带来源小字**：`查到的` / `你定的` / `它补的`，8 号灰字缀在条尾。三种来源在页面上长得一样、一样能改能删——**没有「AI 专区」**。
- **清单与坑位不是世界内容，不进目录**，收在目录下方一行小字里：`已确认 9 / 14 · 坑位 0 · 看清单`。
  - **已确认清单**是一张勾选表：抽出的每条设定列一行，玩家勾了才算事实。来源是标签，勾选才是拍板。
  - **坑位**记已经自相矛盾过、后来修掉的地方。长期日常流一定会撞到，没有这块，聊到几十轮就会前后打架。
- 标题带版本号 `第 3 稿`，只留最新一版，不堆历史。

### 10.4 角色卡：同样聊出来，格子不固定

- **入口**在世界设定页的 `人物` 块：点开就是角色卡列表，末尾一行 `＋ 新建一张`。查看全部人物也在这里，不另开页面。
- 入口三条：`贴一段原文` / `去原著里查` / `你来起一个`。
- 内置只保底几格：**名字、身份、说话方式、音色**——演出必需。
- 其余靠长出来：`性格`／`生气时`／`小动作`／`禁忌`／`关系`／`技能值`／`攻击力`／`好感度`／`持有物`……名字随手起，**卡上永远留一行 `＋ 加一格`**。
- 数值格按「名 值」存（如 `剑术 7`），剧情里能读写：该扣体力时知道扣谁的。
- **卡面上不标来源**：谁贴的、谁编的，都在这张卡里，不再缀小字。
- **连建多张**：底部 `完成` 存卡回人物列表；`完成 · 再建一个` 存下这张、清空接着建。列表里再点 `＋ 新建一张` 也一样。
- **世界书同一套机制**：世界规则、初始属性（初始技能值、攻击力）、势力数值都可自订格，不等我们预设。

### 10.5 来源标注

- **只标在世界设定的条目上**：`查到的` / `你定的` / `它补的`，缀在条尾，8 号灰字。角色卡不标。
- 它编的内容可删可改；**未经玩家确认不算事实**（不直接进设定库）。

### 原则

- **先有稿再修**：不逼玩家逐格填空白。
- **定稿是玩家的动作**，不是系统的动作。
- **允许先随便写，进游戏再改**。
- **页面上不露术语**：一律写「剧本名字 / 原著 / 章节」，不出现「世界书 / 风格书 / 回合额度」这类词。

## 11. 与小手机的关系

- **数据隔离**：文游的角色、世界书、存档都是自己一套，不碰小手机现有的「角色档案」与「世界书」。
- **代码复用**：语音合成、存储、通用组件可以复用，但不共享数据。

## 12. Token 与成本

省钱的顺序不是「少写字」，而是：**少调用 → 多命中缓存 → 少注入无关内容 → 才轮到压字数。**

| 手段 | 做法 | 省在哪 |
| --- | --- | --- |
| **一次调用出一幕** | 导演、演员、叙述是**逻辑上的三层**，默认合成一次请求输出多段；只有角色多、冲突重时才拆成多次 | 调用次数 |
| **稳定前缀** | 系统提示＋设定书固定放最前，不随每轮变动 | 命中提示缓存，单价低一个量级 |
| **按需注入** | 设定书按关键词触发，只取当前场景相关的几条 | 输入 token |
| **滚动摘要** | 近 N 轮原文，再远的压成梗概，更早压成一行印象 | 输入 token |
| **本地检索** | 关键词／标签匹配在浏览器里算，不花 token；不引入向量库 | 检索本身免费 |
| **模型分工** | 导演（规划）用强模型、低频；日常叙述用便宜模型 | 单价 |
| **输出限长** | 一次回复设上限，禁止长篇铺陈 | 输出 token（最贵） |
| **语音懒合成** | 只合成玩家点开的那一条，且只合成台词段 | 语音费用 |
| **快照增量** | 回溯快照只存变化的部分，不整份复制 | 存储，不涉 token |

原则一句话：**能算的不要问模型，能缓存的不要重新发，能短的不要写长。**

## 13. 第一版范围

**做**

- 一个文游项目＝一条线、一批角色、一本设定书、一条存档
- 对话式创建（贴料／查询／先起稿／随口改；角色卡与世界书格不固定）
- 草稿扩写 ＋ 分段输出
- 群像（在场表、信息差、接话权）
- 状态快照 ＋ 覆写式回溯
- 台词语音（按角色音色）

**先不做**

- 多线存档、分支树
- 世界自动推进（计时器、离线事件）
- 联网自动抓取（第一版先支持手动贴文本，链接抓取放到第二版）
- 角色之间的关系图谱可视化
